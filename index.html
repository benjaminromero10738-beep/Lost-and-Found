How It Works

1. Login using your full name and school.

2. Report a lost or found item.

3. Add the item's specific location and photo.

4. Search the system for reported items.

5. Coordinate the recovery through the provided school meeting location.

📝 Report an Item

Please provide accurate information so the item can be easier to identify and recover.

If you found an item, please bring it to the Guard House.

A photo is required before submitting.
